Setup Instructions
Quick Start (5 minutes)
  1. Register System: Enter system name above and click "Register System"
  2. Download Files: Click "Download Agent" to get the Python script and deployment script
  3. Run as Administrator: Open PowerShell as Administrator
  4. Execute Script: Run the deployment script: 
    .\\DEPLOY_<hostname>.ps1
  5. Verify: Check dashboard for metrics appearing
Manual Setup
  1. Download agent_improved_<hostname>.py
  2. Open PowerShell as Administrator
  3. Set environment variables: 
    $env:AGENT_KEY = "your-api-key"
$env:SERVER_URL = "http://your-server:3000"
$env:ENABLE_SCREENSHOTS = "true"
  4. Run the agent: 
    python agent_improved_<hostname>.py
What Data is Collected
  • Every 30 seconds: CPU, RAM, Disk usage, Network info, Logged-in user
  • Every 5 minutes: System screenshot
  • Timezone: All times converted to IST (Indian Standard Time)
  • Security: API key authentication, HTTPS recommended
Troubleshooting
Agent not running?
• Check Python is installed: python --version
• Ensure running as Administrator
• Check server URL is correct and reachable
• Review log file for errors
No metrics appearing?
• Wait 30+ seconds for first metrics
• Check server is running: ping server
• Verify API key is correct
• Check firewall allows outbound connections to port 3000
Screenshots not appearing?
• Wait 5+ minutes for first screenshot
• Verify Pillow is installed: pip list | findstr Pillow
• Check for PIL/ImageGrab errors in logs
