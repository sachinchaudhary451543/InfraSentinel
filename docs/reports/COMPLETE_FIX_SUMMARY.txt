                        HOW IT WORKS NOW (End-to-End Flow)

User enters "hostname" in Terminal UI
    ↓
Portal sends: POST /api/v2/commands {server_id, command}
    ↓
Database: RemoteCommand created with status='pending'
    ↓
Portal starts polling: GET /api/v2/commands/{id} every 2 seconds
Portal starts listening: WebSocket 'command_result' event
    ↓
Agent polls: GET /api/v2/agent/commands (every 30 sec)
    ↓
Agent executes: PowerShell command
    ↓
Agent posts: POST /api/v2/agent/commands/result
    ↓
Portal API receives:
  ├─ Updates database ✓
  ├─ 📡 Broadcasts via WebSocket ✓
  └─ Returns 200 OK ✓
    ↓
Portal UI:
  ├─ WebSocket listener gets real-time result ✓
  ├─ OR polling finds result after 2 seconds ✓
  ├─ Displays output in terminal ✓
  ├─ Shows "✓ Completed" status ✓
  └─ Loads command history ✓
