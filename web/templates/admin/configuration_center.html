Setup guide

Create the app registration

  1. 1Open Microsoft Entra ID → App registrations → New registration. Choose a name such as ServerMonitor Integration; single-tenant is recommended.
  2. 2Copy Directory (tenant) ID from Entra Overview and Application (client) ID from the app’s Overview tab.
  3. 3Go to Certificates & secrets, create a client secret, then copy its Value immediately. The Secret ID will not work.
  4. 4Open API permissions → Microsoft Graph → Application permissions. Add the required permissions below and select Grant admin consent.

Required Graph permissions

Directory.Read.All

Organization and employee directory sync.

Device.Read.All

Entra registered device inventory.

DeviceManagementManagedDevices.Read.All

Intune managed device inventory.

LicenseAssignment.Read.All

Microsoft 365 license inventory.

Adding a permission is not enough. A Global Administrator or Privileged Role Administrator must grant tenant-wide admin consent.
