═══════════════════════════════════════════════════════════════════════════════
  TIMELINE - FROM REGISTRATION TO METRICS VISIBLE
═══════════════════════════════════════════════════════════════════════════════

T+0 seconds
  └─ Admin registers system in portal
  └─ API generates unique 64-char API key
  └─ System stored in database

T+1-5 seconds
  └─ Admin downloads 2 files with API key pre-filled
  └─ agent_improved_<hostname>.py
  └─ DEPLOY_<hostname>.ps1

T+5-30 seconds
  └─ Admin transfers files to Windows system
  └─ System owner or admin opens PowerShell as Administrator
  └─ Runs: .\DEPLOY_<hostname>.ps1

T+30-60 seconds
  └─ Deployment script:
     └─ Checks Admin elevation
     └─ Installs Python dependencies
     └─ Sets environment variables
     └─ Starts Python agent

T+60-90 seconds
  └─ Agent starts:
     └─ Validates server connectivity
     └─ Begins metric collection loop
     └─ Every 30 seconds: POST /api/v2/agent/metrics
     └─ Stores in database
     └─ WebSocket broadcast to dashboard

T+90 seconds
  └─ Dashboard receives WebSocket push
  └─ Updates real-time metrics
  └─ Converts UTC to IST
  └─ Charts update
  └─ System shows "Online" (green)

T+150-300 seconds (5 minutes)
  └─ First screenshot captured
  └─ Sent with metrics payload
  └─ Stored in screenshot table
  └─ Appears in dashboard gallery

═══════════════════════════════════════════════════════════════════════════════
  WHAT HAPPENS AFTER DEPLOYMENT
═══════════════════════════════════════════════════════════════════════════════

Continuous Operation (Agent Running):

  Every 30 Seconds
  ├─ Collect: CPU%, RAM%, Disk%, Network IP, User
  ├─ Create: ISO 8601 UTC timestamp
  ├─ Add: Local IST reference timestamp
  ├─ POST: /api/v2/agent/metrics
  ├─ Store: Database metric record
  ├─ Emit: WebSocket update
  └─ Update: Dashboard real-time

  Every 5 Minutes (in addition to above)
  ├─ Capture: System screenshot (PIL or PowerShell)
  ├─ Compress: JPEG quality 70 (~100 KB)
  ├─ Encode: Base64 for transmission
  ├─ Send: With metrics payload
  ├─ Store: Database screenshot record
  └─ Display: Dashboard screenshot gallery

  On Dashboard
  ├─ Real-time metrics chart (CPU, RAM, Disk)
  ├─ System status indicator (Online/Offline)
  ├─ Last seen timestamp
  ├─ Historical data view (1h, 6h, 12h, 24h, 7d)
  ├─ Screenshots gallery (productivity snapshots)
  ├─ Timezone: All times in IST (UTC+5:30)
  └─ Updates: Live WebSocket every 30 seconds

  Error Handling
  ├─ Network error: Retry with exponential backoff
  ├─ Server unreachable: Log error, continue loop
  ├─ Screenshot failure: Continue with metrics only
  ├─ API key invalid: Log and attempt re-submission
  └─ Timeout: Automatic reconnection
